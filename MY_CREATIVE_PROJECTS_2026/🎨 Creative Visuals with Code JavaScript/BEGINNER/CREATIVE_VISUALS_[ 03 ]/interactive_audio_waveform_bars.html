Web Audio API & FFT Frequency Mathematics

The Web Audio API processes audio signal graphs in real-time. An AnalyserNode applies a Fast Fourier Transform (FFT) to decompose a time-domain wave signal into its constituent frequency components:

Frequency_Bin_Hz(i) = i × (SampleRate / FFT_Size) 
// 1. Initialize Web Audio Context & Analyser Node
const audioCtx = new (window.AudioContext || window.webkitAudioContext)();
const analyser = audioCtx.createAnalyser();

analyser.fftSize = 256; // 128 frequency bins
analyser.smoothingTimeConstant = 0.8;

// 2. Allocate Data Buffers
const bufferLength = analyser.frequencyBinCount;
const frequencyData = new Uint8Array(bufferLength);

// 3. Render Loop Querying FFT Spectrum
function render() {
  analyser.getByteFrequencyData(frequencyData);

  for (let i = 0; i < bufferLength; i++) {
    const value = frequencyData[i]; // 0 to 255
    const percent = value / 255;
    const barHeight = percent * canvas.height;

  }
  requestAnimationFrame(render);
}
