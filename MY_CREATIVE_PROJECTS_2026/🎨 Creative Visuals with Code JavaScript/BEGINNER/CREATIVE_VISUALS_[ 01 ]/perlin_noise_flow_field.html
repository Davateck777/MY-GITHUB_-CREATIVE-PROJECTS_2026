Perlin Noise Math & Vector Engine

In a Perlin Noise Flow Field, a 3D noise function maps spatial coordinates (x, y, z) to a smooth continuous value between [-1, 1]. This scalar value is converted into a vector direction angle:
θ = PerlinNoise(x · scale, y · scale, z) × (2π · Multiplier)
Each particle samples its local vector angle $\theta$, updates its velocity vector $\vec{v} = (\cos\theta, \sin\theta)$, and steps through the grid leaving faint visual trails on canvas. 
// 1. Calculate Perlin Noise Angle at Particle (x, y)
const noiseVal = perlin.noise(
  particle.x * settings.noiseScale,
  particle.y * settings.noiseScale,
  zTimeOffset
);

// 2. Derive Heading Angle
const angle = noiseVal * Math.PI * 2 * settings.angleMultiplier;

// 3. Compute Velocity Acceleration
particle.vx = Math.cos(angle) * settings.speed;
particle.vy = Math.sin(angle) * settings.speed;

// 4. Update Particle Position & Boundary Wrap
particle.x += particle.vx;
particle.y += particle.vy;

if (particle.x < 0) particle.x = canvas.width;
if (particle.x > canvas.width) particle.x = 0;
if (particle.y < 0) particle.y = canvas.height;
if (particle.y > canvas.height) particle.y = 0;
