Three formats, three counting rules

Limits, counting methods, sources and review dates live in one configuration file — not scattered through the interface.

Google Ads · responsive search ad

  • Headlines 3–15 assets, 30 characters each
  • Descriptions 2–4 assets, 90 characters each
  • Display paths 2 optional fields, 15 characters each

Hard limit Double-width CJK characters count as 2. Emoji are counted as 2 here as a conservative assumption.

X · standard post

  • One field 280 weighted characters
  • URLs always count as 23 characters
  • Scripts Latin counts 1, CJK counts 2, emoji count 2

Hard limit Weighted counts come from the bundled official twitter-text parser, not an approximation.

Meta · feed ad

  • Primary text about 125 characters stay visible
  • Headline 40 recommended, ~27 on Facebook Feed
  • Description 30, only rendered on some placements

Recommendation Meta publishes display guidance, not a submission cap. Overlong copy is usually hidden behind “See more”.

Compliance and quality, kept separate

A 280-character post can still be unreadable. The tool reports both signals side by side and never blends them into one misleading number.

Limit compliance

Counts, remaining allowance, overage, near-limit warnings and Google asset-count minimums. Hard limits and display recommendations are labelled differently, because they fail differently.

Copy Readiness Score

Six disclosed checks with published weights: scanability, specificity, capitalisation, repetition, keyword coverage and message coverage. Keyword coverage is excluded, not penalised, when you leave the keyword field empty.

Transparent by construction

Every deduction is listed with the points it removed, so a score of 68 is explainable line by line instead of being a black box.

What this tool does not do

It does not predict performance

The Copy Readiness Score is not Google Ads Quality Score, not a platform approval, and not a forecast of clicks or conversions.

It does not preview with certainty

Previews are illustrative. Real truncation depends on placement, device, font size, language and the platform's own layout engine.

It does not store anything remotely

Saved copy lives in this browser's localStorage. It is not encrypted, not synced, and not visible to anyone else. Export a JSON backup to move it.

It does not publish or rewrite

No account connections, no publishing, no live policy review, no collaboration, and no AI rewrites. You stay the author.
